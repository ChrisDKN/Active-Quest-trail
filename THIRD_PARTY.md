Vendored `extern/SKSEMenuFramework.h` SHA-256: `48416e8220ca777e2fffc2ef2baf21f699ab2e6c409d437f44eec5e311c3524c`. The header is kept unchanged from the existing working integration; an exact upstream commit was not recorded during development.

The Linux build uses [xwin 0.10.0](https://github.com/Jake-Shadle/xwin/tree/0.10.0) to obtain the Microsoft SDK/toolchain. Those downloads are local build inputs and are not part of the repository or mod installer. CommonLibSSE-NG and xwin release archives are checked against their published SHA-256 files.

The meshes, textures, and plugin records are generated by this project's Python scripts. No Skyrim game assets are bundled. The mist and destination shader reference the game's existing texture at runtime.
